# Conditional Statements
Conditional statements are used to make dicision in Python.

## Types
- if
- if...else
- if...elif..else
- Nested if 

## Syntax
```python
if condition:
    # code
```

if the condition is True, the code insides the if block executes.

## Comparision Operators
- ==
- !=
- >
- <
- >=
- <=

## Logical Operators
- and
- or
- not
