# Data Types
A data type tells Python what kind of values a variable stores.

## Type of Data
- int -> Whole numbers
- float -> Decimal numbers
- str -> Text
- bool -> True or False
- complex -> Complex numbers

## type()
The type() is used to check the data type of a variable.

Example: 
age = 20
print(type(age))

## Type Conversion
Type conversion means converting one data type into another.

Functions:
- int()
- float()
- str()
- bool()

Examples:
int("20")
float(10)
str(25)
bool(1)
