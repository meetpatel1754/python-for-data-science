## What is python?
Python is a high-level, interpreted, general-purpose programming language.
It is easy to read, writ, and understand.
Python is widely used in Data Science, Artificial Intelligence, Machine Learning, Web Devlopment, Automation, and many other fields.
Python is one of the most popular programming lenguages because of its simplicity and powerful libraries.
